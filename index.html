怎样让结果更准确

补充数据用途
光波形原始数据、带宽和线性验证用波形积分 / 峰值得到等效宽度，识别次峰、探测器饱和和带宽展宽。
电流波形或完整周期 RMS直接核算电阻平均耗散；光功率无法揭示所有电流。
触发前 C 两端电压、局部高压波形检查欠充电、供电下陷；阴极最低电压不能替代这些量。

实际脉冲串、漏触发与重复频率频率必须是整段测量时间内的有效平均频率。
收光比例、波长设置、功率计校准把读数换算为总出光；功率计需支持对应脉冲条件。
壳温、器件 L–I 曲线及阻值型号改善电流估算，核对降额和电阻重复脉冲能力。
计算依据与适用范围

高斯光脉冲：E = P峰值 × FWHM × √π / (2√ln2)，形状系数约 1.064467。矩形为 1。自定义等效宽度为积分面积 / 峰值。

P平均 = f触发 × 同样光脉冲数 × E。占空比显示 FWHM × 脉冲数 × f，并另列形状系数加权的能量等效占空比。高斯模型要求脉冲间隔远大于脉宽。

初始电容储能参考量为 ½CV²，电路充电常数近似 RC。C28 是耦合电容，模型忽略其他供能和损耗路径，因此储能参考量不是整个电路光能的严格上限，经验比也不等于激光器效率。

电流粗估：I阈值 + P光峰值 / [P典型 / (I典型 − I阈值)]。不自动做温度补偿，不用一个典型点外推保证性能。

有完整周期 RMS 时，P电阻 = I_RMS²R。否则必须给电流 FWHM，以假定电流形状估算；高斯电流的平方积分系数为 0.752692，矩形为 1，不包含未建模振铃。
