# 激光脉冲工作台 · Laser Pulse Workbench

**当前版本：v1.0.0**

一个可直接在浏览器中运行的离线激光脉冲计算工具。面向脉冲激光器调试，通过平均光功率与光波形估算峰值、单脉冲光能，并提供基于实测校准的驱动条件预测。

不依赖服务器、在线接口或前端框架。普通使用者无需安装 Node.js、Python 或其他运行环境。

## 下载与启动

1. 从 [Releases](https://github.com/fengbihe/laser-pulse-workbench/releases) 下载 `laser-pulse-workbench-v1.0.0.zip`，或使用 GitHub 的 **Code → Download ZIP**。
2. 解压后双击 `index.html`，用 Chrome、Edge、Safari 等现代浏览器打开。
3. 选择“① 实测换算”或“② 驱动预测”。

Windows、macOS 等带有现代浏览器的平台可使用。页面支持窄屏布局；移动设备能否打开本地 HTML，取决于系统与浏览器的本地文件访问方式。

无需联网即可完成计算。GitHub 仓库提供源文件和下载入口，未自动部署在线网站。

## 两种计算模式

### ① 实测换算

适用于已测得平均光功率与光波形的情况。

| 输入 | 单位 / 含义 |
| --- | --- |
| 平均光功率 | mW，功率计读数 |
| 实际触发频率 | kHz，测量时间内的有效平均触发频率 |
| 实测光宽 | ns，半高全宽 FWHM；多峰时指主峰分量宽度 |
| 波形形状 | 高斯、矩形、多峰或自定义等效宽度 |
| 收光比例（选填） | 默认 100%，表示功率计读数已经等于总出光 |
| 每次触发相同波形数（选填） | 默认 1；多个波形需具有相同形状和能量 |

输出总平均光功率、峰值光功率、每个波形的光能，以及基于激光器典型参数的电流峰值粗估。该模式不需要高压和电容，修改校准区的驱动参数不会改变实测换算结果。

**示例**：0.4 mW、200 kHz、6.5 ns 高斯脉冲，完整收光、每触发一个脉冲，对应单脉冲光能 **2 nJ**、峰值约 **0.289 W**。默认光电模型对应电流粗估约 **320 mA**；这不是实测电流。

### ② 驱动预测

适用于已有实测校准，想比较改变驱动条件后的近似趋势。

1. 在实测模式填好光功率、频率及光波形。
2. 展开“把这次实测保存为驱动预测的校准点”，填写该次测量对应的高压、电容和 TRIG；优先提供触发前电容两端的实测电压。
3. 点击“保存实测校准并进入驱动预测”。软件保存校准，并复制参数到独立的预测输入区。
4. 修改预测高压、电容、频率或光波形，查看平均光功率、峰值与单波形光能的估算结果。

两种模式分别保留各自的主要输入。修改预测条件不会自动改写实测基准；换激光器、串联阻值、布局或工作区间后，应重新校准。

**光脉宽是独立输入**：软件不会从 TRIG 自动预测光脉宽。若填写了实测电容电压，预测优先使用它，单改设定高压不会改变预测光能。没有校准或经验比时，不会直接给出预测结果。

## 波形与图表

- **高斯形**：适合近似单峰光脉冲。
- **矩形**：按矩形面积换算。
- **多峰**：用主峰、第二峰及可选第三峰的高斯分量叠加。可填写相对分量幅度、中心延迟与各自 FWHM。重叠时由整条曲线最高点计算峰值，同时计入所有分量的能量。
- **自定义等效宽度**：输入基线扣除后的积分面积 / 峰值；不臆测绘制波形。

多峰属于同一波形，不要再重复计入“每次触发的相同光脉冲数”。次峰分量能量占比按分量积分划分，不等于按波谷切割后的面积占比。

默认时间轴为 **−20～20 ns**，光功率轴为 **0～1 W**，修改输入不会自动改变坐标。支持两个轴分别缩放、“适配当前波形”和“恢复坐标”。超出视图会裁切并提示；缩放不改变计算结果。虚线用于显示已建立的校准基准。

## 数学与物理依据

记触发频率为 f、每触发相同波形数为 N、收光比例为 α：

```text
总平均光功率 = 功率计读数 / α
每波形光能 E = 总平均光功率 / (f × N)
峰值光功率 = E / 等效宽度
```

高斯波形的等效宽度为 `1.064467 × FWHM`，矩形为其脉宽。多峰对全部高斯分量求面积，并用数值计算的叠加最高点归一化：

```text
g(t) = Σ aᵢ × exp[−4 ln(2) × ((t − dᵢ) / wᵢ)²]
等效宽度 = 1.064467 × Σ(aᵢ × wᵢ) / max(g)
```

驱动预测采用校准后的储能参考比：

```text
电容初始储能参考量 Ec = ½ × C × Vc²
参考比 k = 校准时每触发总光能 / 校准时 Ec
预测每触发总光能 ≈ k × Ec
预测平均光功率 ≈ f × k × Ec
预测每波形光能 ≈ k × Ec / N
```

**储能公式有明确电学依据，k 保持不变则是经验假设。** k 包含器件、电路和光路的综合影响，不是激光器本身的电光效率。C28 是耦合电容时，其初始储能也不能未经完整能量分析就视为整个电路光输出的严格上限。

电流粗估采用阈值与典型工作点构建线性关系：

```text
斜率 ≈ 典型光峰值 / (典型电流 − 阈值电流)
电流峰值粗估 ≈ 阈值电流 + 光峰值 / 斜率
```

单个典型工作点不能反映纳秒瞬态、完整 L–I 曲线或温度效应，因此不能用该粗估确认没有过流。

## 参数与状态检查

“激光器手册参数”位于输入区下方，可展开编辑。默认采用 PLD-808-2W 手册中列出的典型值与极限值：

| 参数 | 默认值 |
| --- | --- |
| 典型工作点 | 1.5 A 对应 1.6 W，条件为 100 ns、0.1%、25℃ |
| 阈值电流 | 60 mA |
| 光峰值极限 | 4 W |
| 正向电流极限 | 4 A |
| 脉宽极限 | 200 ns |
| 占空比极限 | 0.1% |
| 反向电压极限 | 3 V |
| 工作温度范围 | −40～100℃ |

状态面板提示光峰值、占空比、反向电压、温度，以及预测模式的简化 RC 充电恢复条件。光 FWHM 占空比与实际电流占空比不能混为一谈。

“工作状态与电阻核算”在页面最底部，默认收起，仅供实际串联电阻的电路选用。完整周期电流 RMS 可用于 `P = I_RMS²R`；否则只能按输入电流脉宽和假定形状估算。连续额定功率与重复脉冲能力须查具体型号，不能由封装尺寸推定。

## 适用范围与已知限制

- 驱动预测是单点校准后的近似，不是电路仿真，不能保证电容、高压、频率大幅变化后仍准确。
- 不自动模拟寄生电感、ESR/ESL、开关边沿、欠充电、非线性损耗、温升或器件损伤。
- TRIG 宽度不等于光宽，阴极对地负尖峰不等于电容电压或激光电流。
- 光探测器和功率计应在线性范围，具有足够带宽，并正确处理基线、收光、衰减及背景。
- 多峰是参数化近似；当前版本不能直接导入示波器 CSV 并积分。
- 不提供 PD 电压换算。收光比例未知时，局部 PD 信号不能直接代表总出光。
- 低于某项极限不能证明器件整体安全；该工具不能替代电流、器件两端电压和温度测量。

## 保存、导出与隐私

- “保存参数”使用当前浏览器的本地存储；更换浏览器、电脑、路径或清理数据后，不保证保留。
- “导出结果”生成 JSON，包含输入、校准点及计算结果，用于记录；v1.0.0 尚不支持导入恢复。
- “恢复示例”会清除本地保存并恢复示例参数与坐标。
- 页面无需联网，不发送实验参数到服务器。分享项目不包含原使用者浏览器中的参数。
- 仓库包含软件与示例，不包含硬件设计文件、原始照片或原厂 PDF。

## 开发与验证

普通使用无需安装依赖。开发测试需要现代 Node.js（建议 20 或更新版本）：

```sh
npm install
npx playwright install chromium
npm test
```

可通过 `BROWSER_PATH` 环境变量指定已有浏览器可执行文件。测试覆盖公式、多峰积分、校准缩放、输入校验、模式隔离、固定坐标缩放、保存导出及桌面/手机布局；测试截图写入系统临时目录。

修改计算逻辑后请运行测试。反馈问题时请附计算模式、输入值、预期与实际结果、浏览器版本，以及可复现步骤；实验数据可先匿名化。
