# 激光脉冲工作台

离线运行的激光光功率计算工具。下载项目后，直接用现代浏览器打开 `index.html`，无需安装依赖或联网。

## 功能

- **实测换算**：由平均光功率、频率及光脉冲形状，计算峰值光功率、单脉冲光能，并粗估激光电流。
- **驱动预测**：使用实测校准点，按电容初始储能参考量估算高压、电容、频率变化后的光功率。
- 支持高斯、矩形、第二/第三峰叠加、自定义等效宽度。
- 支持固定坐标、横纵轴缩放、参数本地保存与结果 JSON 导出。
- 手册参数可修改；底部可选折叠区提供电阻核算。

详细操作见 [使用说明](使用说明.md)。示例值不代表使用者的实测工况。

## 计算范围

驱动预测采用校准后近似模型，不是完整电路仿真。TRIG 脉宽不等于光脉宽；模型反推的电流不等于实际电流测量。未加入 PD 电压换算，未知收光比例下不能将 PD 接收功率视作激光器总出光。

项目默认参数来自 PLD-808-2W 产品规格书中列出的典型工作点，不能代替对应器件的完整规格、脉冲负载与热条件核验。本仓库不包含硬件设计文件、原始照片、原厂 PDF 或实验人员浏览器内保存的参数。

## 开发验证（仅开发者需要）

需要 Node.js。安装测试依赖和 Chromium：

```sh
npm install
npx playwright install chromium
npm test
```

也可通过 `BROWSER_PATH` 环境变量指定本机浏览器可执行文件。测试覆盖公式、多峰积分、校准缩放、输入校验、模式切换、固定坐标、保存导出及桌面/手机布局。截图存放在系统临时目录。

普通使用者只需打开 HTML，不需要执行上述步骤。
